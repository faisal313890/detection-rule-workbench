Selections AND their field predicates. Value lists OR by default; |all requires every list item. Condition supports lowercase and, or, not and parentheses.

Event fixtures

Each record requires event_id, source and flat scalar fields. Optional Boolean expected_match labels define the behavior you want to test; they are not verified attack labels. Raw EVTX, vendor logs and nested ECS events are not imported.

Rules, fingerprints and interpretation limits
    

    Small grammar. Explicit behavior.
    Use Field or Field|eq, |contains, |startswith, |endswith, or |exists. Combine a text/equality operator with |all for list values.
    Strings use Unicode casefolding. Field names and source metadata are case-sensitive. Integers and Booleans are strictly typed; 4625 is different from "4625". Dots in field names are literal.
    Missing or null values fail ordinary comparisons. |exists: true checks that the key exists, including a null value. Source product and category must both match exactly.
    Interpret results in context.
    Real detection engineering requires representative telemetry, reliable labels, field mapping and operational testing. These examples demonstrate local rule behavior. They do not establish that a tuned exclusion is safe for production.
    There are no regexes, wildcards, aggregations, correlations, time windows, SIEM backends or network lookups in this profile. Unsupported constructs produce validation errors.
